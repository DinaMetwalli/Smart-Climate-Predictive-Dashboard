Upload Your Own Files

Use this page to upload your own files for analysis. Please keep in mind the following when selecting your files:

  • Each file uploaded must contain the following columns: (Date, Anomaly, Region)
  • The dates must be monthly, following the format YYYYMM.
  • Each file can have only one continent inside for the region.
  • The list of available continents is: ['africa', 'asia', 'europe', 'northAmerica', 'southAmerica', 'oceania']
  • Continent names should go in the 'Region' column and follow the same structure as the list above.
  • Accepted file types are CSV and NC.

If these conditions aren't met, your analysis won't be processed.
